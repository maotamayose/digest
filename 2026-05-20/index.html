関数呼び出しグラフを視覚的に追跡できるツールが存在しない

大規模コードベースの構造理解（"function call graph viewer"）がHN で繰り返し要望されている。AI コーディング支援は増えたが既存コードの構造可視化は未解決。IDE 拡張では対応が断片的でスタンドアロン解析ツールの市場が空白。Ask HN: What developer tool do you wish existed in 2026?

ローカル CI 再現環境の欠如——本番 CI に45分、手元で試せない

開発マシンで CI 環境をそのまま再現できないというペインが複数言及。Act など既存ツールは設定の複雑さが障壁で実用率が低い。Ask HN: What developer tool do you wish existed in 2026?

広告ゼロ・手順だけ見たいレシピアプリが存在しない

レシピ・料理カテゴリのユーザー投稿が平均223文字と他カテゴリより長く、フラストレーションが深い。「広告まみれのサイトに飛ばさず手順だけ見たい」という要望が集中。Reddit Analysis – nomusica.com

Markdown ビューアの「重量級 vs 最小化」の二択問題

VSCode/Obsidian は重すぎ、軽量ビューアは wikilinks・数式・Mermaid に対応しない。Obsidian の有料機能と完全無料軽量の間の中間市場が未充足。Show HN: mdviewer – GitHub
