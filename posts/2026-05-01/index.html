【セキュリティ】Linuxに「一般ユーザーがroot（最高権限）になれる」脆弱性

■ 何が起きた？ Linuxに「Copy Fail」と呼ばれる深刻な脆弱性（CVE-2026-31431、CVSS 7.8）が公開されました。影響を受けるのは Ubuntu・Red Hat・Amazon Linux・SUSE などの主要ディストリビューションで、なんと2017年に混入したコードが今まで見つかっていなかったことになります。

仕組みを平たく言うと——Linuxには暗号処理を行う内部モジュールがあり、そこに特定の手順でアクセスすると、通常は読み書きできないはずのカーネル（OS の心臓部）の領域に4バイトだけ書き込めてしまいます。この4バイトで「su コマンド」（権限を切り替えるコマンド）の動作を書き換え、root権限を奪取するという攻撃です。

■ なぜ重要？ 「root が取れる」とは、そのサーバーで何でもできる状態になるということです。ファイルの読み書き・設定変更・他ユーザーへのなりすまし・マルウェア常駐——すべてが可能になります。開発環境・CI/CDサーバー・本番サーバーいずれも対象です。

■ 対処 各ディストリビューターが既にセキュリティパッチを公開しています。Linuxサーバーを管理している方は今週中にカーネルアップデートを実行してください。

# Ubuntu / Debian
sudo apt update && sudo apt upgrade

# RHEL / Amazon Linux
sudo yum update kernel

② 米国でついに「周辺の治安・学校の情報」を不動産サイトで見せられるようになった

米住宅都市開発省（HUD）が、不動産エージェントが「犯罪率」や「学校の評価」を顧客に提供しても法律違反にならないと明確化しました。

背景として、公正住宅法（Fair Housing Act）という差別禁止の法律があり、これを根拠にZillow・Redfin等の大手不動産サイトは2021年以降、そうした情報をサイトから削除していました。今回の方針転換で、米国では物件探しの「周辺環境データ」が再び表に出てくることになります。

日本でも「ハザードマップ」「学区情報」の提供範囲は常に議論になっており、米国の動向は参考になります。

参考: https://www.housingwire.com/articles/hud-says-realtors-can-discuss-crime-and-school-data/
