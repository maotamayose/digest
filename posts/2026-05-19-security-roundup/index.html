【セキュリティまとめ】5/7〜5/19の重大ニュース14本——「守備側のツール自体が落ち、開示→悪用の猶予も消え、単独で守れる防御線が一つも残っていない」2週間

ここ2週間で、これまで暗黙の前提だった「公式」「MFA有効」「フルパッチ」「猶予期間」「言語ランタイム」が同時に揺らぎました。3つの軸で纏めます。

■ 軸① 守備側のツール自体が攻撃の入り口になった これまで「守ってくれる側」だったツールが、連続で攻撃面に変わりました。 ・Checkmarx の Jenkins AST プラグイン（脆弱性検査ツール）が TeamPCP に汚染、公式 Jenkins Marketplace 経由で配布 ・Grafana の GitHub トークンが窃取され、コードベース全流出＋恐喝未遂（5/19公表） ・PHPUnit に引数インジェクション脆弱性。CI で PHPUnit を回している PHP 案件は任意コマンド実行に直結（JPCERT 注意喚起） ・JDownloader 公式サイトが侵害、Win/Linux インストーラが Python 製 RAT に差し替え ・npm ワーム Shai-Hulud の本体ソースが公開され、クローンキャンペーンが週末再噴出（5/19）

■ 軸② 開示→悪用の「猶予時間」が消えた これまでは「CVE公開後にパッチを当てる猶予」が前提でしたが、その猶予がほぼゼロになりました。 ・PraisonAI（AIエージェント基盤）の認証バイパス CVE-2026-44338 — 公開からたった4時間で攻撃者がスキャン開始 ・NGINX rewrite モジュール CVE-2026-42945（CVSS 9.2、18年潜伏）— 5/15開示、5/19には野外悪用観測 ・cPanel CVE-2026-41940 — PoC 公開直後に大規模悪用、ホスティング数百万サイト影響 ・Google が「AI で開発された初の野外ゼロデイ」を確認。脆弱性発見＋攻撃コード生成の両方を AI が担う実環境例

■ 軸③ 単独で守れる防御線が一つも残っていない 「これさえあれば」と頼っていた防御線が、それぞれ単独で破られました。 ・MFA有効の前提が崩れた: Tycoon2FA がデバイスコードフィッシングで Microsoft 365 を強奪（MFA を有効化していても突破） ・フルパッチの前提が崩れた: MiniPlasma（cldflt.sys 0-day、5/19 PoC公開）— 完全更新済み Windows 11 でも SYSTEM 権限奪取 ・有名インフラの前提が崩れた: Cisco SD-WAN Controller CVE-2026-20182（CVSS 10.0）ゼロデイ実環境悪用、Microsoft Exchange CVE-2026-42897 は 5/19 時点でも正式パッチなし ・言語ランタイムの前提が崩れた: PHP 本体に11件の CVE（5/7修正）— SOAP の Use After Free（CVE-2026-6722）でリモートコード実行のおそれ等、重大4件を含む。SOAP 連携の多い自社PHP環境は影響範囲の特定が必須

■ これだけは覚えてほしい 「公式だから」「MFA有効だから」「フルパッチだから」「いつもの言語だから」のどれ一つも、もう単独で安全前提にできません。 業務PCに新規ツールを入れる前は提供元と中身を確認し、見慣れない認証画面（特に「デバイスコード」を入力させる画面）が出たら一旦止めて上長にすぐ相談するようにしましょう！

■ 自分はこう動く 「猶予4時間」が現実になった以上、CVE開示の通知導線とパッチ反映のラグを最短化する仕組みを、自分の関わるソースコード管理（GitLab）・自社運用Webサーバ・CI/CD依存パッケージ・PHPランタイムまわりで見直していきたいです。SO 課の方々と連携しながら、対象バージョンと依存OSSの棚卸しを継続的に進めていきたいです。
