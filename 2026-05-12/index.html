CIのテスト選定がいまだ手作業で精度も低い

大規模・多層アーキテクチャのチームで「どのテストスイートを回すか」をエンジニアが手動判断しており、パスベースの自動選定は不正確で見落としが出る。「LLMに差分を解析させて関連テストを提案・flaky検出も込み」というニーズが複数挙がる。CIに刺さるアドオンとして小さく作って課金しやすい。同スレッドでは「ローカルでCIをプロトタイプできない」「Postmanが肥大化しすぎ」も頻出。pain度: 76/100。Hacker News: What developer tool do you wish existed in 2026?

AIエージェントの「惜しいけど間違い」をPRを切らず指摘したい

Claude Code / Cursor が「もっともらしいが誤った変更」を出してくるが、フルPRを作らずにインラインで注釈・差し戻しする手段がないという不満。crit.md など個人が作り始めており、AI支援開発の出力レビューUXに穴がある。GitHub App や CLI として小さく作れて、cubic/CodeRabbit 等とは別レイヤー（人間が手で直したい層）を狙える。pain度: 74/100。Hacker News: What are you working on? (April 2026)

2026年でも残る「複数ソースの情報統合」「Sheets整形」の手作業

スクショ・ダウンロードの出所と整理がいまだに手作業

「スクリーンショットがどのアプリ／サイトから来たか」を覚えていてくれて、スクショとダウンロードを自動分類するツールへの需要。r/indiehackers の投稿者が同じ痒みでmac向けreverse file searchを作り、HNの自動化スレッドでも別の人が「スマホもPCもギャラリーを手で整理し続けている」と同じ不満を表明。複数人が同じペインを言っており、macユーティリティ／ブラウザ拡張として買い切り課金しやすい。pain度: 70/100。r/indiehackers / Hacker News（同種の不満）
